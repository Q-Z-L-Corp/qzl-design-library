# Community standards

We aim to make QZL Design Library a welcoming, useful place to learn and collaborate.

Everyone participating in project discussions or contributions is expected to:

- Be respectful and considerate.
- Discuss ideas and code in good faith.
- Welcome different backgrounds, experience levels, and perspectives.
- Give actionable feedback without personal attacks.
- Respect privacy and avoid sharing someone else's personal information.

Harassment, discrimination, intimidation, and deliberate disruption are not acceptable. Project maintainers may remove content or restrict participation when needed to protect the community.

Before public release, the project maintainers should add a private contact address or reporting channel here so concerns can be reported confidentially.
