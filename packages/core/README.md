# @qzlcorp/core

Shared helpers used by the QZL Design Library component packages.

This supporting package has not been published yet. Application developers typically install `@qzlcorp/react` or `@qzlcorp/react-native` instead.

```sh
pnpm add @qzlcorp/core
```

The package currently provides bounded numeric values, class-name composition, theme preference helpers, and a safe block parser used by the Markdown editors. The parser returns data structures; render its text fields as text rather than injecting HTML.
